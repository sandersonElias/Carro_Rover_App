## Conversão para PDF/Word

Para converter o relatório para PDF ou Word:

### Opção 1: Pandoc (Recomendado)
```bash
pandoc relatorio_tecnico_abnt.md -o relatorio_tecnico.pdf
```

### Opção 2: Markdown PDF (VS Code)
1. Instale a extensão "Markdown PDF"
2. Abra o arquivo `relatorio_tecnico_abnt.md`
3. Use Ctrl+Shift+P → "Markdown PDF: Export (pdf)"

### Opção 3: Google Docs
1. Copie o conteúdo do arquivo .md
2. Cole no Google Docs
3. Formate conforme necessário
4. Exporte como PDF

## Normas ABNT Aplicadas

### NBR 10719:2011 (Relatórios Técnicos)
- Estrutura: Introdução, Desenvolvimento, Conclusão
- Formatação: Fonte Times New Roman 12pt
- Espaçamento: 1.5 entre linhas
- Margens: Esquerda e superior 3cm; Direita e inferior 2cm
- Numeração: Páginas centralizadas no rodapé

### NBR 6023:2018 (Referências)
- Formato autor-data
- Ordem alfabética
- Itálico em títulos de periódicos
- Maiúsculas em abreviaturas
